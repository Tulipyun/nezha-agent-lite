# Changelog

## v0.1.0

- Initial public release of the Zig implementation for Linux/OpenWrt.
- Nezha v0.20.5 core RPCs, host/state reporting and IPv4/IPv6 ICMP.
- Configurable fixed workers, bounded queues, connection reuse and deadlines.
- Correct distribution naming and deduplicated mounted-storage accounting.
- Server address, port and client secret are required runtime parameters.
- Public documentation, repeatable local tests, CI and static ARM64/x86_64 builds.
- Example/test configuration contains no real deployment endpoints or credentials.
