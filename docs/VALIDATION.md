# 验证记录与测量范围

本页只保留技术摘要。真实服务器地址、密钥、账号、设备 IP、进程 ID、
本机绝对路径、SSH 配置和原始运行日志不属于公开发行内容。

**功能验证**

- 基础版本完成 23 项单元测试；首次公开版增加了 endpoint/端口必填与可配置性的回归测试。
- 独立 hyper-h2 服务端完成 14 项测试：连接累计发送超过 64 KiB、极小/零窗口、
  拒绝与损坏回执、缺失 trailer、RST_STREAM、GOAWAY、握手/读写超时。
- ARM64 与 x86_64 的 OpenWrt QEMU 回归各 13 项，覆盖每 30 秒 8/16/32 个任务、
  IPv6、raw socket、全部超时、慢回执、重连、控制任务、队列溢出及 procd。
- 四核 ARMv8 OpenWrt 真机核心版本完成约 30 分钟测试：61 批、1912 个任务与
  1912 个确认回执，包含 IPv4、IPv6、主机名、慢回执和连接恢复。
- 发行版名称及磁盘统计修复后，在真实 v0.20.5 兼容面板验证了持续状态与 ICMP 回报，
  并人工核对了展示结果；两个目标重新完成了虚拟机回归。

首次公开版在上述核心实现上移除了预置 endpoint，将手动探针改为显式环境变量配置，
并禁用 TCP Nagle 以避免短控制帧与小流窗口的延迟交互；
这部分重新运行单元测试、协议互操作测试和交叉编译。历史长测不是对每个后续提交的认证。
24–72 小时长期验证仍建议在实际部署环境完成。

**代表性资源测量**

在同一台四核 ARMv8 OpenWrt 设备上，每 10 秒采样一次，共 19 次、约 180 秒。
原 Go Agent 保持运行；Zig 配置为 32 个 ICMP worker 与 2 个结果 worker。
两个 Agent 使用各自当时的真实面板任务。

| 指标 | Go v0.20.5 | Zig 精简实现 |
| --- | ---: | ---: |
| 平均 RSS | 14.08 MiB | 1.04 MiB |
| 平均 CPU，单核满载=100% | 1.6897% | 0.4925% |
| 线程数 | 11 | 36 |
| 打开文件描述符 | 7–9 | 7 |

CPU 来自 /proc 累计进程时间的差值，RSS 为采样统计。此设备没有可用的 PSS 数据。
这些数字反映当前精简功能和负载，不能直接推导完整功能等价版本或其他硬件的收益。
